# Контекст для дальнейшей доработки

Это персональная надстройка Codex для VS Code. Её полная сохранённая версия находится в `~/.codex-ui/releases/1.2/src/`. Изменения установленной копии в `~/.vscode/extensions/` нельзя считать единственным экземпляром исходников.

Сохранённые функции:

- «История»: текущий проект / все проекты, загрузка всех страниц, полнотекстовый поиск, группы, перенос нескольких чатов, архивирование, восстановление и переименование.
- «Аккаунт и лимиты»: карточка в духе Claude Code, тёплый акцент, графические полосы, проценты использования и остатка, локальное время сброса, время обновления, светлая/тёмная/контрастная темы, адаптация к ширине панели.
- Индикаторы: зелёный — выполнение; синий — ожидание ответа или подтверждения; белый — чат в активной вкладке. Приоритет: ожидание действия > выполнение > открытая вкладка. В светлой теме белый индикатор заменён тёмным для видимости.
- Состояния чатов распространяются в поиск и свёрнутые группы; открытая вкладка отслеживается при переключении и закрытии вкладок и групп редактора.
- Редактор чатов использует штатный интерфейс Codex во вкладках, с ленивым восстановлением, немедленным стартом без ожидания заголовка и ограниченным повтором при медленной загрузке.
- Диагностика не пишет содержимое сообщений и данные входа.

`extension.js` содержит логику истории, состояния и команд. `account-view.js` отвечает за визуализацию аккаунта; сетевых ресурсов и скриптов в карточке нет, данные экранируются, действует Content Security Policy. `patch-openai-extension.js` адаптирует редактор Codex и передаёт только `threadId` и безопасные поля статуса через событие `slava.codex.threadStatus.v1`; последнее состояние хранится в `process[Symbol.for('slava.codex.threadStatus.v1')]`.

Отдельный процесс app-server у надстройки используется для истории и аккаунта. Для работы и ожидания чатов источником служит основной редактор: состояние его процесса нельзя достоверно заменять статусом отдельного app-server. Карта `runtimeStatuses` имеет приоритет над результатами фонового перечитывания истории.

При обновлении официального Codex сначала прочитайте новую установленную версию и код. Сравните с сохранённой совместимой базой в `compatibility/`, обновите точечные преобразования редактора и регистрацию штатных представлений. Сохраните проверку версии, контрольной суммы и уникальности замен; не обходите их ради применения старого кода к новой сборке. Проверьте начало/завершение работы, ожидание подтверждения/ответа, переключение/закрытие вкладок, поиск и группы, карточку лимитов и повторный запуск восстановления. После изменений обновите `release.json`, соберите VSIX через `build.py` и обновите сохранённый ZIP.

В исходниках сохранено поведение версии 1.2. Комплект предназначен для восстановления на совместимой версии и как полная база для дальнейшей адаптации; совместимость с любым будущим Codex не обещается.
