# Сохранённая сборка Codex History UI 1.2

Комплект создан 12 ноября 2026 года. Постоянное место на этом Mac: `~/.codex-ui/`. Эта папка расположена отдельно от `~/.vscode/extensions/`, поэтому переустановка надстройки не заменяет сохранённые исходники.

Внутри находятся исходники надстройки, установочный пакет VSIX, исходный и модифицированный код проверенной версии Codex, скрипт сборки и скрипт восстановления. История чатов, аккаунты, токены и настройки входа в комплект не включены и при восстановлении не переносятся.

История изменений версий ведётся в [CHANGELOG.md](CHANGELOG.md).

Для восстановления откройте `restore.command` двойным щелчком или выполните в терминале:

```bash
node ~/.codex-ui/restore.js
```

После восстановления выполните в VS Code `Cmd+Shift+P → Developer: Reload Window`.

Для проверки совместимости без изменения файлов:

```bash
node ~/.codex-ui/restore.js --check
```

Скрипт находит установленный Codex через реестр VS Code, проверяет версию и контрольную сумму, при необходимости устанавливает сохранённую надстройку, возвращает патч редактора, подключение цветовых индикаторов и скрытие штатной боковой панели. Перед изменениями создаётся копия в `~/.codex-ui-backups/`. Повторный запуск не создаёт изменений, если сборка уже восстановлена. Скрипт использует существующие Node.js и VS Code; дополнительные пакеты не устанавливает.

Проверенная пара версий: UI `1.2` + OpenAI Codex `26.1111.21308`. Если очередное обновление Codex изменит внутреннее устройство редактора, восстановление остановится до установки и записи патча. В таком случае нужно адаптировать только интеграцию с новой версией, используя сохранённые исходники. Сам UI и его требования восстанавливать по памяти не требуется. Комплект не содержит полной установочной сборки официального Codex и не выполняет автоматический откат его версии.

Исходники находятся в `releases/1.2/src/`, пакет — в `releases/1.2/codex-history-ui-1.2.vsix`, инструкция для следующей доработки — в `HANDOFF.md`. Резервные копии исходного и изменённого редактора лежат в `releases/1.2/compatibility/` и служат материалом для адаптации; копировать их поверх другой версии Codex нельзя.

Сохраните резервную копию комплекта в своём обычном хранилище. После распаковки комплект работает из любого каталога: относительные пути вычисляются от расположения скрипта.

Для пересборки после осознанного изменения исходников используется стандартный Python без дополнительных библиотек:

```bash
python3 ~/.codex-ui/build.py
```

Пересборка обновляет пакет и контрольные суммы. Она не делает патч автоматически совместимым с новой версией Codex. Для новой совместимости сначала доработайте патч и список проверенных версий/контрольных сумм в `release.json`, проверьте результат на временной копии и только затем пересобирайте комплект.
