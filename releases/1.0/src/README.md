# Codex History UI

Локальная адаптация интерфейса Codex для VS Code `1.96.2+` и расширения OpenAI Codex `26.1106.51428`.

Расширение добавляет в штатный контейнер Codex два сворачиваемых представления: «Аккаунт и лимиты» и «История». Чаты открываются штатным редактором Codex во вкладках основной области VS Code.

Реализовано:

- история текущего проекта и всех проектов с загрузкой всех страниц;
- полнотекстовый поиск по активным и архивным чатам;
- штатные секции Codex как группы, включая создание, переименование, удаление и перенос нескольких чатов;
- архив, восстановление и переименование активных и архивных чатов через app-server;
- индикаторы работающих чатов и ожидания действия пользователя;
- сведения об аккаунте, тарифе, лимитах и локальном времени сброса;
- строка состояния и безопасный журнал диагностики без текстов сообщений и секретов;
- ленивое восстановление неактивных вкладок;
- предупреждение при медленной загрузке без замены загрузчика фатальным экраном и один ограниченный повтор;
- немедленный старт вкладки без ожидания получения заголовка чата;
- настройка `codexHistory.enabled` для возврата к одному штатному представлению Codex.

Перенос данных Claude Code не выполняется и не входит в эту поставку.

## Индикаторы чатов

В версии `1.0` зелёный кружок обозначает выполнение запроса, синий — ожидание ответа или подтверждения, белый — чат в активной вкладке основного редактора. Ожидание действия имеет приоритет над выполнением, выполнение — над открытой вкладкой. В светлой теме индикатор открытой вкладки становится тёмным для контраста. Состояния поступают из основного расширения Codex, а открытая вкладка отслеживается при переключении и закрытии вкладок и групп редактора.

## Панель аккаунта

В версии `1.1.0` аккаунт и лимиты отображаются в компактной карточке с тёплым акцентом: графические полосы использования, остаток лимита, локальное время сброса и время последнего обновления. Карточка поддерживает светлую, тёмную и контрастную темы VS Code.

## Установка

```bash
code --install-extension /путь/codex-history-ui-1.0.vsix --force
```

После установки выполните `Developer: Reload Window`. Патч загрузки штатного редактора применяется отдельно через `patch-openai-extension.js`: скрипт проверяет точную версию и контрольную сумму, создаёт резервную копию в `~/.codex-ui-backups/` и останавливается без изменений для несовместимой сборки.

## Откат патча штатного расширения

```bash
node patch-openai-extension.js restore ~/.codex-ui-backups/<каталог-копии>
```

Companion-расширение можно отключить настройкой `Codex History UI: Enabled`. Обновление OpenAI Codex может заменить патч штатного редактора; для новой версии установщик остановится без изменений, пока не будет добавлена явная совместимость.

Протокол реализован поверх документированного [Codex app-server](https://developers.openai.com/codex/app-server).
